# Sistema de Gestión de Productos

Esta es una aplicación backend desarrollada con **Java** y **Spring Boot** utilizando **Maven** como gestor de dependencias. Permite realizar operaciones sobre un catálogo de productos a través de una arquitectura limpia (controladores, servicios y repositorios).

# Requisitos Previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:
Java JDK 17 o superior.


## 🛠️ Instrucciones para Ejecutar el Proyecto

Sigue estos pasos en tu terminal para poner en marcha la aplicación:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   cd TU_REPOSITORIO
   ```
